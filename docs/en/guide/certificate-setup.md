# Certificate Setup

To monitor HTTPS traffic, you need to install the CA certificate generated by Cheolsu Proxy in your system.

## Certificate File Location

Cheolsu Proxy generates CA certificates in the following locations:

- **macOS**: `~/Library/Application Support/com.cheolsu-proxy/cheolsu-proxy.cer`
- **Windows**: `%APPDATA%/com.cheolsu-proxy/cheolsu-proxy.cer` (coming soon)

## macOS Setup

### 1. Installation via Keychain Access

1. **Launch Keychain Access app**

   - Search for "Keychain Access" in Spotlight
   - Or Applications > Utilities > Keychain Access

2. **Select Keychain**

   - Select "login" keychain from the left sidebar
   - For system-wide use, select "System" keychain

3. **Import Certificate**

   - Choose File > Import Items... from the menu
   - Select the `~/Library/Application Support/com.cheolsu-proxy/cheolsu-proxy.cer` file
   - Click "Open"

4. **Trust Settings**
   - Double-click the imported certificate
   - Expand the "Trust" section
   - Set "When using this certificate" to "Always Trust"
   - Close the window and enter your password when prompted
   - Enter administrator password

### 2. Installation via Terminal

```bash
# Add certificate file to system keychain
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Library/Application\ Support/com.cheolsu-proxy/cheolsu-proxy.cer
```

### 3. Verify Installation

```bash
# Verify certificate is properly installed
security find-certificate -c "cheolsu-proxy" /Library/Keychains/System.keychain
```

## Windows Setup (Coming Soon)

### 1. Using Certificate Manager

1. **Launch Certificate Manager**

   - Press Windows key + R and type `certmgr.msc`
   - Press Enter

2. **Add to Trusted Root Certification Authorities**

   - Select "Trusted Root Certification Authorities" > "Certificates" from the left tree
   - Right-click > "All Tasks" > "Import..."

3. **Import Certificate**
   - Select the `%APPDATA%/com.cheolsu-proxy/cheolsu-proxy.cer` file
   - Click "Next" to complete the wizard

### 2. Installation via PowerShell

```powershell
# Import certificate
Import-Certificate -FilePath "$env:APPDATA\com.cheolsu-proxy\cheolsu-proxy.cer" -CertStoreLocation Cert:\LocalMachine\Root
```

```bash
# Copy certificate to system certificate store
sudo cp ~/.config/com.cheolsu-proxy/cheolsu-proxy.cer /usr/local/share/ca-certificates/cheolsu-proxy.crt

# Update certificate store
sudo update-ca-certificates
```

### 2. CentOS/RHEL/Fedora

```bash
# Copy certificate to system certificate store
sudo cp ~/.config/com.cheolsu-proxy/cheolsu-proxy.cer /etc/pki/ca-trust/source/anchors/cheolsu-proxy.crt

# Update certificate store
sudo update-ca-trust
```

### 3. Manual Setup

```bash
# Add certificate to individual applications
# Firefox
certutil -A -n "cheolsu-proxy" -t "C,," -i ~/.config/com.cheolsu-proxy/cheolsu-proxy.cer -d sql:$HOME/.mozilla/firefox/*.default

# Chrome/Chromium
# Chrome uses system certificate store, so system setup above is required
```

## Browser-Specific Settings

### Chrome/Chromium

Chrome uses the system certificate store, so the OS-specific setup above is sufficient.

### Firefox

Firefox uses its own certificate store:

1. **Open Firefox Settings**

   - Type `about:preferences#privacy` in the address bar
   - Click "View Certificates" in the "Certificates" section

2. **Import Certificate**
   - Select the "Authorities" tab
   - Click "Import..." button
   - Select the certificate file
   - Check "Trust this CA to identify websites"
   - Click "OK"

### Safari

Safari uses macOS Keychain, so the macOS setup above is sufficient.

## Troubleshooting

### Certificate Not Trusted

1. **Reinstall Certificate**

   - Delete existing certificate and reinstall
   - Clear browser cache and cookies

2. **Check Permissions**

   - Verify installation with administrator privileges
   - Check file permissions

3. **Time Synchronization**
   - Verify system time is correct
   - Check certificate validity period

### Cannot Access HTTPS Sites

1. **Verify Proxy Settings**

   - Ensure system proxy is set to `127.0.0.1:8100`
   - Verify Cheolsu Proxy is running

2. **Check Firewall**

   - Ensure firewall is not blocking port 8100
   - Verify Cheolsu Proxy has network access

3. **Other Proxy Software**
   - Check for conflicts with other proxy or VPN software
   - Verify proxy setting priority

### Certificate Error Messages

**"NET::ERR_CERT_AUTHORITY_INVALID"**

- CA certificate not properly installed
- Certificate reinstallation required

**"NET::ERR_CERT_COMMON_NAME_INVALID"**

- Certificate Common Name doesn't match requested domain
- Verify Cheolsu Proxy's dynamic certificate generation

**"NET::ERR_CERT_DATE_INVALID"**

- System time is incorrect
- Certificate has expired (regeneration required)

## Security Considerations

### Certificate Security

- CA certificates are for local use only
- Do not transmit externally
- Regular certificate renewal (planned)

### Network Security

- Recommended for local network use only
- Caution on public networks
- Restrict access with firewall settings

### Data Protection

- All traffic data stored locally only
- No transmission to external servers
- Privacy policy compliance
