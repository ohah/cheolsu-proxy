# Cheolsu Proxy

Rust와 Tauri로 구축된 간단한 Man In The Middle 프록시입니다.

## 주요 기능

- **TLS 지원**: HTTPS 트래픽 가로채기 및 분석
- **인증서 관리**: 자동 인증서 생성 및 설치
- **크로스 플랫폼**: Windows, macOS, Linux 지원
- **사용자 친화적**: 직관적인 GUI 인터페이스
