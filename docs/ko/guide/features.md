# 주요 기능

Cheolsu Proxy는 네트워크 트래픽 모니터링과 분석을 위한 다양한 기능을 제공합니다.

## 🔐 HTTP/HTTPS 지원

### HTTP 트래픽

- 모든 HTTP 요청과 응답을 실시간으로 캡처
- 요청 헤더, 바디, 쿼리 파라미터 분석
- 응답 상태 코드, 헤더, 바디 확인

### HTTPS 트래픽

- TLS/SSL 암호화된 트래픽 디코딩
- 자동 생성된 CA 인증서를 통한 안전한 중간자 공격
- 다양한 TLS 버전 지원 (1.0, 1.1, 1.2, 1.3)

## 🔒 TLS 1.0/1.1 레거시 지원

### 하이브리드 TLS 핸들러

- 최신 TLS 버전과 레거시 버전을 모두 지원
- 자동 TLS 버전 감지 및 적절한 핸들러 선택
- 레거시 시스템과의 호환성 보장

### 지원하는 TLS 버전

- TLS 1.0 (레거시)
- TLS 1.1 (레거시)
- TLS 1.2 (현재 표준)
- TLS 1.3 (최신 표준)

## 🖱️ 직관적인 GUI

### 다크/라이트 테마

- 사용자 선호에 따른 테마 선택
- 시스템 테마 자동 감지
- 눈의 피로를 줄이는 색상 구성

### 반응형 디자인

- 다양한 화면 크기에 최적화
- 모바일 기기에서도 사용 가능
- 접근성 고려한 UI/UX

## ⌨️ 고급 설정 옵션

### 네트워크 설정

- **리스닝 주소**: 기본값 `127.0.0.1` (로컬호스트)
- **포트**: 기본값 `8100`, 사용자 정의 가능
- **바인딩 인터페이스**: 특정 네트워크 인터페이스 선택

### 프록시 모드

- **투명 프록시**: 클라이언트가 인식하지 못하는 프록시
- **명시적 프록시**: 클라이언트가 직접 설정하는 프록시
- **리버스 프록시**: 서버 앞단에서 동작하는 프록시

## 🔍 상세한 트래픽 분석

### 요청 정보

- **HTTP 메서드**: GET, POST, PUT, DELETE, PATCH 등
- **URL**: 전체 경로와 쿼리 파라미터
- **헤더**: 모든 HTTP 헤더 정보
- **바디**: 요청 페이로드 (JSON, XML, Form Data 등)
- **타임스탬프**: 정확한 요청 시간

### 응답 정보

- **상태 코드**: HTTP 상태 코드 (200, 404, 500 등)
- **응답 시간**: 요청부터 응답까지의 소요 시간
- **헤더**: 모든 응답 헤더
- **바디**: 응답 데이터
- **크기**: 요청/응답 데이터 크기

## 🎯 강력한 필터링

### 메서드별 필터링

- GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS
- 여러 메서드 동시 선택 가능
- 실시간 필터링 적용

### 상태 코드별 필터링

- 2xx (성공): 200, 201, 204 등
- 3xx (리다이렉션): 301, 302, 304 등
- 4xx (클라이언트 오류): 400, 401, 404 등
- 5xx (서버 오류): 500, 502, 503 등

### URL 패턴 검색

- 정규식 지원
- 대소문자 구분/무시 옵션
- 부분 일치 및 전체 일치

## ❌ 요청 관리

### 개별 요청 삭제

- 특정 요청만 선택적으로 제거
- 실수로 삭제한 경우 되돌리기 불가 (향후 개선 예정)
- 삭제된 요청은 통계에서 제외

### 전체 정리

- 모든 요청을 한 번에 삭제
- 메모리 사용량 최적화
- 새로운 세션 시작

## 🔐 보안 기능

### 사용자별 고유 CA 인증서

- 각 사용자마다 고유한 CA 인증서 생성
- 개인키는 바이너리에 포함되지 않음
- 보안 강화된 인증서 관리

### 인증서 자동 생성

- 첫 실행 시 자동으로 CA 인증서 생성
- 사용자 개입 없이 즉시 사용 가능
- 인증서 만료 자동 갱신 (향후 지원)

### 로컬 전용

- 모든 데이터는 로컬에만 저장
- 외부 서버로 데이터 전송 없음
- 개인정보 보호 보장

## 📊 성능 최적화

### 메모리 효율성

- 스트리밍 방식의 데이터 처리
- 대용량 트래픽도 안정적으로 처리
- 메모리 사용량 모니터링

### 빠른 응답

- 비동기 처리로 UI 블로킹 방지
- 실시간 업데이트
- 최소한의 지연 시간

## 🚀 확장성

### 플러그인 시스템 (향후 지원)

- 사용자 정의 핸들러 추가
- 새로운 프로토콜 지원
- 커스텀 분석 도구

### API 제공 (향후 지원)

- REST API를 통한 외부 연동
- 웹훅 지원
- 다른 도구와의 통합
