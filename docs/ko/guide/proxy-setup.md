# 프록시 설정

Cheolsu Proxy의 기본 설정을 변경하는 방법을 안내합니다.

## 🔧 포트 변경

### 포트를 변경하는 이유

- 기본 포트 8100이 다른 프로그램에서 사용 중일 때
- 회사나 학교에서 특정 포트만 허용할 때
- 보안상 다른 포트를 사용하고 싶을 때

### 포트 변경 방법

1. Cheolsu Proxy에서 **설정** 버튼을 클릭합니다
2. **프록시 포트** 필드에 원하는 포트 번호를 입력합니다
   - 예: `8080`, `9000`, `3128` 등
3. **저장** 버튼을 클릭합니다
4. 프록시를 재시작합니다

### 브라우저 설정도 변경하기

포트를 변경했다면 브라우저 설정도 함께 변경해야 합니다:

1. **Chrome/Edge**: 설정 → 고급 → 시스템 → 프록시 서버 설정 열기
2. **Firefox**: 설정 → 일반 → 네트워크 설정
3. 새로 설정한 포트 번호로 변경합니다

## 🌐 네트워크 설정

### 로컬에서만 사용 (기본값)

- **설정**: `127.0.0.1` (로컬호스트)
- **용도**: 본인 컴퓨터에서만 프록시 사용
- **보안**: 가장 안전한 설정

### 다른 기기에서도 사용

다른 기기(스마트폰, 태블릿)에서도 프록시를 사용하려면:

1. **설정** → **네트워크 주소**를 `0.0.0.0`으로 변경
2. **포트**를 원하는 번호로 설정
3. **저장** 후 프록시 재시작

### 모바일 기기 설정

1. PC와 모바일이 같은 Wi-Fi에 연결되어 있는지 확인
2. PC의 IP 주소를 확인합니다:
   - **Windows**: `ipconfig` 명령어 실행
   - **macOS**: `ifconfig` 명령어 실행
3. 모바일 기기에서 Wi-Fi 설정 → 고급 옵션 → 프록시 설정
4. **수동** 선택 후 **서버**: `[PC_IP]:[포트]` 입력

## ⚙️ 자동 시작 설정

### 컴퓨터 시작 시 자동 실행

1. **설정** → **일반** 탭
2. **"시스템 시작 시 자동 실행"** 옵션을 켭니다
3. **저장** 버튼을 클릭합니다

이제 컴퓨터를 켤 때마다 Cheolsu Proxy가 자동으로 실행됩니다.

### 프록시 자동 시작

1. **설정** → **일반** 탭
2. **"프로그램 시작 시 프록시 자동 시작"** 옵션을 켭니다
3. **저장** 버튼을 클릭합니다

프로그램이 실행되면 프록시도 자동으로 시작됩니다.

## 📊 로그 설정

### 로그 레벨 변경

1. **설정** → **로그** 탭
2. **로그 레벨**을 선택합니다:
   - **간단**: 오류만 표시 (빠른 성능)
   - **보통**: 일반 정보 포함 (기본값)
   - **상세**: 모든 정보 표시 (디버깅용)

### 로그 파일 저장

1. **설정** → **로그** 탭
2. **"로그 파일 저장"** 옵션을 켭니다
3. 로그 파일이 저장될 위치를 선택합니다

## 🔒 보안 설정

### 접근 제한

특정 IP 주소에서만 프록시를 사용하도록 제한할 수 있습니다:

1. **설정** → **보안** 탭
2. **"허용된 IP 주소"** 목록에 IP 주소를 추가합니다
3. 예: `192.168.1.100`, `10.0.0.0/24` 등

### 도메인 필터링

특정 웹사이트를 차단하거나 허용할 수 있습니다:

1. **설정** → **보안** 탭
2. **차단할 도메인** 목록에 도메인을 추가합니다
3. 예: `ads.example.com`, `*.malware.com` 등

## 🎨 사용자 인터페이스

### 테마 변경

1. **설정** → **일반** 탭
2. **테마**를 선택합니다:
   - **라이트**: 밝은 테마
   - **다크**: 어두운 테마
   - **시스템**: 시스템 설정 따름

### 언어 변경

1. **설정** → **일반** 탭
2. **언어**를 선택합니다:
   - **한국어**
   - **English**

## 📱 모바일 연결 설정

### QR 코드로 연결

1. **설정** → **모바일 연결** 탭
2. **QR 코드 생성** 버튼을 클릭합니다
3. 모바일 기기에서 QR 코드를 스캔합니다
4. 자동으로 프록시 설정이 적용됩니다

### 수동 설정 정보

QR 코드 대신 수동으로 설정할 때 필요한 정보:

- **프록시 서버**: `[PC_IP]:[포트]`
- **인증서**: 다운로드 링크 제공

## ❓ 설정 관련 문제 해결

### 포트 변경 후 연결 안 됨

1. 방화벽에서 새 포트가 허용되는지 확인
2. 다른 프로그램이 해당 포트를 사용하는지 확인
3. 프록시를 재시작해보세요

### 모바일에서 연결 안 됨

1. PC와 모바일이 같은 Wi-Fi에 연결되어 있는지 확인
2. PC의 방화벽 설정 확인
3. PC의 IP 주소가 올바른지 확인

### 자동 시작이 안 됨

1. 관리자 권한으로 Cheolsu Proxy를 실행해보세요
2. 시스템 시작 프로그램 목록에 추가되었는지 확인
3. 바이러스 백신 프로그램이 차단하는지 확인

## 💡 팁

### 권장 포트 번호

- **개발용**: `8000-8999`
- **일반용**: `9000-9999`
- **회사용**: `3128, 8080, 8888`

### 네트워크 성능 향상

- 로그 레벨을 "간단"으로 설정하면 성능이 향상됩니다
- 불필요한 도메인 필터링을 제거하세요
- 정기적으로 로그 파일을 정리하세요
