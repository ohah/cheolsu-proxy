# 기본 사용법

Cheolsu Proxy를 처음 사용하는 분들을 위한 간단한 가이드입니다.

## 🚀 시작하기

### 프로그램 실행

1. Cheolsu Proxy를 다운로드하고 설치합니다
2. 프로그램을 실행합니다
3. 메인 화면이 나타납니다

## ✅ 사용 확인

### 프록시가 작동하는지 확인

1. 브라우저에서 `http://httpbin.org/ip`에 접속합니다
2. IP 주소가 표시되면 프록시가 정상 작동합니다
3. Cheolsu Proxy의 로그 탭에서 요청을 확인할 수 있습니다

## 🛑 프록시 중지

### 프록시 중지하기

1. Cheolsu Proxy에서 **"프록시 중지"** 버튼을 클릭합니다

## 🔒 HTTPS 사이트 사용하기

HTTPS 사이트를 사용하려면 인증서 설치가 필요합니다.

### 인증서 설치

1. Cheolsu Proxy에서 **설정** → **인증서**를 클릭합니다
2. **"인증서 설치"** 버튼을 클릭합니다
3. 시스템에 인증서가 설치됩니다
4. 브라우저를 재시작합니다

> **주의**: 인증서 설치 후 일부 보안 경고가 나타날 수 있습니다. 이는 정상적인 현상입니다.
