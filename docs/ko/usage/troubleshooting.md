# 문제 해결

Cheolsu Proxy 사용 중 발생하는 일반적인 문제들을 해결하는 방법을 안내합니다.

## 🚫 프록시가 시작되지 않음

### 포트가 이미 사용 중

**증상**: "포트가 이미 사용 중입니다" 오류 메시지

**해결 방법**:

1. 다른 포트 번호로 변경해보세요 (예: 8080, 9000)
2. 설정 → 프록시 포트에서 포트 변경
3. 프록시 재시작

### 방화벽 차단

**증상**: 프록시는 시작되지만 연결이 안 됨

**해결 방법**:

1. **Windows**: Windows Defender 방화벽에서 Cheolsu Proxy 허용
2. **macOS**: 시스템 환경설정 → 보안 및 개인정보보호 → 방화벽에서 허용
3. 바이러스 백신 프로그램에서도 허용 설정

### 관리자 권한 필요

**증상**: "권한이 부족합니다" 오류

**해결 방법**:

1. Cheolsu Proxy를 우클릭
2. "관리자 권한으로 실행" 선택
3. 또는 관리자 계정으로 로그인

## 🌐 웹사이트에 접속이 안 됨

### 브라우저 프록시 설정 확인

**증상**: 모든 웹사이트에 접속 불가

**해결 방법**:

1. 브라우저 프록시 설정이 올바른지 확인
2. HTTP 프록시: `127.0.0.1:8100` (또는 설정한 포트)
3. HTTPS 프록시: `127.0.0.1:8100` (또는 설정한 포트)

### 인터넷 연결 확인

**증상**: 프록시 없이는 접속되지만 프록시 사용 시 접속 안 됨

**해결 방법**:

1. 인터넷 연결 상태 확인
2. DNS 설정 확인 (8.8.8.8, 1.1.1.1 사용 권장)
3. 프록시를 일시 중지하고 직접 접속 테스트

### 특정 사이트만 접속 안 됨

**증상**: 일부 사이트에서만 접속 불가

**해결 방법**:

1. 해당 사이트가 프록시를 차단하는지 확인
2. 프록시 설정에서 도메인 필터링 확인
3. 다른 브라우저에서 테스트

## 🔒 HTTPS 사이트 문제

### 인증서 경고

**증상**: "연결이 안전하지 않습니다" 경고

**해결 방법**:

1. 인증서가 올바르게 설치되었는지 확인
2. 설정 → 인증서에서 "인증서 재생성" 클릭
3. 브라우저 재시작

### 인증서 설치 실패

**증상**: 인증서 설치 버튼이 작동하지 않음

**해결 방법**:

1. 관리자 권한으로 Cheolsu Proxy 실행
2. 바이러스 백신 프로그램 일시 중지
3. 수동 설치 방법 사용 (인증서 관리 가이드 참고)

### 일부 브라우저에서만 경고

**증상**: Chrome에서는 되지만 Firefox에서는 경고

**해결 방법**:

1. 각 브라우저별로 인증서 저장소 확인
2. Firefox: 설정 → 개인정보 보호 및 보안 → 인증서
3. Chrome: 설정 → 고급 → 시스템 → 인증서 관리

## 📱 모바일 연결 문제

### 모바일에서 프록시 연결 안 됨

**증상**: 모바일 기기에서 프록시 설정 후 연결 불가

**해결 방법**:

1. PC와 모바일이 같은 Wi-Fi에 연결되어 있는지 확인
2. PC의 IP 주소가 올바른지 확인
3. PC의 방화벽에서 모바일 IP 허용

### 모바일 인증서 설치 문제

**증상**: 모바일에서 HTTPS 사이트 접속 불가

**해결 방법**:

1. 인증서 파일을 모바일로 전송
2. 모바일에서 인증서 설치
3. 인증서 신뢰 설정 활성화

## ⚡ 성능 문제

### 연결이 느림

**증상**: 웹사이트 로딩이 매우 느림

**해결 방법**:

1. 로그 레벨을 "간단"으로 설정
2. 불필요한 도메인 필터링 제거
3. 프록시 재시작

### 메모리 사용량이 높음

**증상**: Cheolsu Proxy가 많은 메모리를 사용

**해결 방법**:

1. 로그 파일 정리
2. 동시 연결 수 제한
3. 프로그램 재시작

## 🔧 설정 문제

### 설정이 저장되지 않음

**증상**: 설정을 변경해도 다음 실행 시 초기화됨

**해결 방법**:

1. Cheolsu Proxy를 관리자 권한으로 실행
2. 설정 파일 권한 확인
3. 바이러스 백신에서 설정 파일 차단 확인

### 자동 시작이 안 됨

**증상**: 컴퓨터 시작 시 Cheolsu Proxy가 자동 실행되지 않음

**해결 방법**:

1. 설정 → 일반에서 "시스템 시작 시 자동 실행" 확인
2. Windows: 작업 스케줄러에서 확인
3. macOS: 로그인 항목에서 확인

## 📊 로그 관련 문제

### 로그가 표시되지 않음

**증상**: 로그 탭에서 아무것도 보이지 않음

**해결 방법**:

1. 로그 레벨을 "상세"로 설정
2. 프록시 재시작
3. 웹사이트에 접속하여 로그 생성 확인

### 로그 파일이 너무 큼

**증상**: 로그 파일이 매우 커짐

**해결 방법**:

1. 로그 레벨을 "간단"으로 설정
2. 로그 파일 자동 회전 설정
3. 정기적으로 로그 파일 삭제

## 🆘 고급 문제 해결

### 네트워크 진단

```bash
# 프록시 연결 테스트
curl -x http://127.0.0.1:8100 http://httpbin.org/ip

# 포트 사용 확인 (Windows)
netstat -an | findstr :8100

# 포트 사용 확인 (macOS)
lsof -i :8100
```

### 로그 파일 위치

- **Windows**: `%APPDATA%\CheolsuProxy\logs\`
- **macOS**: `~/Library/Logs/CheolsuProxy/`

### 설정 파일 위치

- **Windows**: `%APPDATA%\CheolsuProxy\config\`
- **macOS**: `~/Library/Application Support/CheolsuProxy/config/`
