# 인증서 설치

HTTPS 사이트를 사용하기 위한 인증서 설치 방법을 안내합니다.

## 🔐 인증서가 필요한 이유

### HTTPS 사이트 사용

- **HTTP 사이트**: 인증서 없이도 사용 가능
- **HTTPS 사이트**: 인증서 설치 필요 (예: 은행, 쇼핑몰, 소셜미디어)

### 보안 경고 해결

인증서를 설치하지 않으면 다음과 같은 경고가 나타납니다:

- "연결이 안전하지 않습니다"
- "인증서를 신뢰할 수 없습니다"
- "NET::ERR_CERT_AUTHORITY_INVALID"

## 📥 간단한 설치 방법

### 자동 설치 (권장)

1. Cheolsu Proxy에서 **설정** → **인증서**를 클릭합니다
2. **"인증서 설치"** 버튼을 클릭합니다
3. 시스템에 자동으로 설치됩니다
4. 브라우저를 재시작합니다

### 설치 확인

1. 브라우저에서 `https://www.google.com`에 접속해보세요
2. 경고 없이 정상적으로 접속되면 설치가 완료된 것입니다

## 🖥️ 운영체제별 설치

### Windows 설치

1. **자동 설치**: Cheolsu Proxy에서 "인증서 설치" 버튼 클릭
2. **수동 설치**:
   - 인증서 파일을 더블클릭
   - "인증서 설치" 클릭
   - "로컬 컴퓨터" 선택
   - "신뢰할 수 있는 루트 인증 기관"에 저장

### macOS 설치

1. **자동 설치**: Cheolsu Proxy에서 "인증서 설치" 버튼 클릭
2. **수동 설치**:
   - Keychain Access 실행
   - 인증서 파일을 System 키체인으로 드래그
   - 인증서를 더블클릭하여 "Always Trust" 설정

## 📱 모바일 기기 설치

### iPhone/iPad

1. 인증서 파일을 이메일이나 AirDrop으로 전송
2. 파일을 탭하여 설치
3. **설정** → **일반** → **VPN 및 기기 관리**에서 프로필 설치
4. **설정** → **일반** → **정보** → **인증서 신뢰 설정**에서 활성화

### Android

1. 인증서 파일을 기기로 전송
2. **설정** → **보안** → **인증서 설치**
3. "CA 인증서" 선택
4. 인증서 파일 선택하여 설치

## ✅ 설치 확인 방법

### 브라우저에서 확인

1. **Chrome/Edge**: 설정 → 고급 → 시스템 → 인증서 관리
2. **Firefox**: 설정 → 개인정보 보호 및 보안 → 인증서 → 인증서 보기
3. "Cheolsu Proxy CA" 또는 "Cheolsu Proxy" 인증서가 있는지 확인

### 테스트 사이트 접속

다음 사이트들이 경고 없이 접속되면 설치가 완료된 것입니다:

- `https://www.google.com`
- `https://www.github.com`
- `https://www.stackoverflow.com`

## 🔄 인증서 갱신

### 자동 갱신

- Cheolsu Proxy가 자동으로 인증서를 갱신합니다
- 만료 30일 전에 갱신 알림이 표시됩니다
- 알림이 나타나면 "갱신" 버튼을 클릭하세요

### 수동 갱신

1. **설정** → **인증서**에서 "인증서 재생성" 클릭
2. 기존 인증서가 제거되고 새 인증서가 설치됩니다
3. 브라우저를 재시작하세요

## 🚨 문제 해결

### 인증서 설치 실패

**해결 방법**:

1. 관리자 권한으로 Cheolsu Proxy 실행
2. 바이러스 백신 프로그램 일시 중지
3. 수동 설치 방법 시도

### 설치 후에도 경고가 나타남

**해결 방법**:

1. 브라우저 캐시 삭제
2. 브라우저 재시작
3. 인증서를 다시 설치

### 특정 사이트에서만 경고

**해결 방법**:

1. 해당 사이트의 인증서가 올바른지 확인
2. 브라우저의 인증서 저장소 확인
3. 프록시를 재시작

## 🔒 보안 주의사항

### 인증서 사용 목적

- **개발 및 테스트**: 로컬 개발 환경에서만 사용
- **개인 사용**: 개인 컴퓨터에서만 사용
- **프로덕션 금지**: 실제 서비스에서는 사용하지 마세요

### 정기적 관리

- 1년마다 인증서 갱신
- 사용하지 않을 때는 인증서 제거
- 정기적으로 보안 업데이트 확인

## ❓ 자주 묻는 질문

### Q: 인증서를 설치해도 안전한가요?

**A**: 네, 안전합니다. Cheolsu Proxy는 로컬에서만 작동하며, 외부로 데이터를 전송하지 않습니다.

### Q: 모든 브라우저에서 작동하나요?

**A**: 네, Chrome, Firefox, Safari, Edge 등 모든 주요 브라우저에서 작동합니다.

### Q: 인증서를 제거하고 싶어요

**A**: Cheolsu Proxy 설정에서 "인증서 제거" 버튼을 클릭하거나, 운영체제의 인증서 저장소에서 수동으로 제거할 수 있습니다.

### Q: 회사 컴퓨터에서도 사용할 수 있나요?

**A**: 회사 정책에 따라 다릅니다. IT 부서에 문의하시기 바랍니다.
