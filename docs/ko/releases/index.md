# 릴리즈 노트

Cheolsu Proxy의 버전별 업데이트 내역을 확인할 수 있습니다.

## 🚀 최신 릴리즈

### v1.0.0 (개발 중)

- **릴리즈 예정일**: 2025년 Q4
- **주요 기능**:
  - 기본 프록시 기능
  - HTTPS 트래픽 가로채기
  - 자동 인증서 생성 및 설치
  - macOS 지원
  - 직관적인 GUI 인터페이스
