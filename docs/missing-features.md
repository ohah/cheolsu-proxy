# 미구현 기능 목록

> 최종 업데이트: 2026-03-09
>
> Charles Proxy, mitmproxy 대비 cheolsu-proxy에 없는 기능을 정리한 문서입니다.

## 인터셉트 / 디버깅

| 기능                 | Charles | mitmproxy | 설명                                                                  |
| -------------------- | :-----: | :-------: | --------------------------------------------------------------------- |
| Breakpoints          |    O    |     O     | 요청/응답을 실시간으로 멈추고 수동 편집 후 전송                       |
| 정규식 기반 Rewrite  |    O    |     O     | 정규식으로 헤더/바디의 특정 부분만 치환 (현재는 전체 교체만 가능)     |
| No Caching 토글      |    O    |     X     | Cache-Control 등 캐시 무효화 헤더 자동 삽입                           |
| No Gzip 토글         |    O    |     X     | Accept-Encoding 헤더 자동 제거                                        |
| 트랜잭션 비교 (Diff) |    O    |     X     | 두 요청/응답 간 차이점 비교                                           |
| DNS Spoofing         |    O    |     O     | 특정 도메인의 DNS를 로컬에서 오버라이드 (TCP/UDP 등 비-HTTP 트래픽용) |

## 프로토콜

| 기능          | Charles | mitmproxy | 설명                                    |
| ------------- | :-----: | :-------: | --------------------------------------- |
| HTTP/3 (QUIC) |    X    |     O     | QUIC 기반 HTTP/3 지원                   |
| gRPC 디코딩   |    X    |     O     | gRPC 요청/응답을 Protobuf로 자동 디코딩 |
| Raw TCP / UDP |    X    |     O     | HTTP가 아닌 일반 TCP/UDP 트래픽 캡처    |
| AMF 디코딩    |    O    |     X     | Flash/Flex AMF 프로토콜 디코딩 (레거시) |

## 프록시 모드

| 기능              | Charles | mitmproxy | 설명                                            |
| ----------------- | :-----: | :-------: | ----------------------------------------------- |
| Reverse Proxy     |    O    |     O     | 특정 서버 앞에 투명하게 배치되는 리버스 프록시  |
| Transparent Proxy |    X    |     O     | OS 레벨(iptables 등)에서 트래픽 자동 리다이렉트 |
| WireGuard 모드    |    X    |     O     | VPN 터널을 통한 트래픽 캡처 (모바일 기기 용이)  |

## TLS / 인증서

| 기능                           | Charles | mitmproxy | 설명                                            |
| ------------------------------ | :-----: | :-------: | ----------------------------------------------- |
| Client SSL Certificate (mTLS)  |    O    |     O     | 클라이언트 인증서를 프록시에 설정하여 상호 인증 |
| 사용자 지정 CA 인증서 가져오기 |    O    |     O     | 외부 CA 인증서/키 파일 직접 지정                |

## 콘텐츠 뷰어

| 기능                     | Charles | mitmproxy | 설명                                            |
| ------------------------ | :-----: | :-------: | ----------------------------------------------- |
| Protobuf 뷰어            |    O    |     O     | Protocol Buffers 바이너리 데이터 디코딩 및 표시 |
| multipart/form-data 뷰어 |    O    |     O     | 폼 데이터 파싱 및 구조화 표시                   |
| urlencoded 뷰어          |    O    |     O     | 쿼리 파라미터 키-값 테이블 표시                 |

## 세션 / 내보내기

| 기능                 | Charles | mitmproxy | 설명                                                    |
| -------------------- | :-----: | :-------: | ------------------------------------------------------- |
| 세션 저장 / 복원     |    O    |     O     | 전체 세션을 파일로 저장하고 나중에 다시 로드            |
| 다양한 코드 내보내기 |    X    |     O     | httpie, Python requests, raw HTTP 등 (현재 curl만 지원) |

## 네트워크 시뮬레이션

| 기능            | Charles | mitmproxy | 설명                                             |
| --------------- | :-----: | :-------: | ------------------------------------------------ |
| 대역폭 프리셋   |    O    |     X     | 3G/4G/56k 등 미리 정의된 네트워크 환경 프리셋    |
| Repeat Advanced |    O    |     X     | 요청을 N회 반복 + 동시 요청 수(concurrency) 설정 |
