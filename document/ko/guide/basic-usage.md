# 기본 사용법

Cheolsu Proxy를 처음 사용하는 분들을 위한 간단한 가이드입니다.

## 🚀 시작하기

### 프로그램 실행

1. Cheolsu Proxy를 다운로드하고 설치합니다
2. 프로그램을 실행합니다
3. 메인 화면이 나타납니다

### 인증서 설치

#### macOS

1. Cheolsu Proxy에서 **설정** → **인증서**를 클릭합니다
2. **"인증서 설치"** 버튼을 클릭합니다
3. 시스템에 인증서가 설치됩니다
4. **Keychain Access**에서 인증서를 더블클릭하여 **"항상 신뢰"**로 설정합니다

## ✅ 사용 확인

### 프록시가 작동하는지 확인

1. 임의의 네트워크 요청
2. 요청이 화면에 업데이트 되는지 확인.

## 📦 HAR 내보내기

캡처된 HTTP 트랜잭션을 HAR (HTTP Archive) 1.2 형식으로 내보낼 수 있습니다.

### Desktop

1. 네트워크 대시보드에서 트래픽을 캡처합니다
2. 상단의 **다운로드** 버튼을 클릭합니다
3. 저장 경로를 선택하면 `.har` 파일이 생성됩니다

### TUI

1. 네트워크 화면에서 `e` 키를 누릅니다
2. 현재 디렉토리에 `cheolsu-proxy-YYYYMMDD-HHMMSS.har` 파일이 생성됩니다

> HAR 파일은 Chrome DevTools, Firefox, Charles Proxy 등 다양한 도구에서 열 수 있습니다.
