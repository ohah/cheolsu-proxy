# 기본 사용법

Cheolsu Proxy를 처음 사용하는 분들을 위한 간단한 가이드입니다.

## 🚀 시작하기

### 프로그램 실행

1. Cheolsu Proxy를 다운로드하고 설치합니다
2. 프로그램을 실행합니다
3. 메인 화면이 나타납니다

### 인증서 설치

#### macOS

1. Cheolsu Proxy에서 **설정** → **인증서**를 클릭합니다
2. **"인증서 설치"** 버튼을 클릭합니다
3. 시스템에 인증서가 설치됩니다
4. **Keychain Access**에서 인증서를 더블클릭하여 **"항상 신뢰"**로 설정합니다

## ✅ 사용 확인

### 프록시가 작동하는지 확인

1. 임의의 네트워크 요청
2. 요청이 화면에 업데이트 되는지 확인.

## 🛑 프록시 중지

### 프록시 중지하기

1. Cheolsu Proxy에서 **"프록시 중지"** 버튼을 클릭하거나 앱을 종료합니다.
