# 지원 예정

Cheolsu Proxy의 향후 지원 예정 기능들을 확인할 수 있습니다.

## 개발 로드맵

### 추후 지원 예정 기능

- **플랫폼 지원**:
  - Windows 지원

- **프록시 모드**:
  - Reverse Proxy
  - Transparent Proxy
  - SOCKS5 Proxy

- **내보내기/가져오기**:
  - HAR 내보내기
  - 세션 저장/불러오기

- **고급 기능**:
  - Server-side Replay (응답 모킹)
  - 로그 분석 기능
  - 성능 최적화

- **확장 기능**:
  - 플러그인 시스템
