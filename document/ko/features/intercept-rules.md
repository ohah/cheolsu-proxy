# 인터셉트 규칙

와일드카드 패턴 기반으로 HTTP 요청/응답을 가로채고 수정할 수 있습니다.

---

## 액션 타입

### 1. Block (차단)

요청을 차단하고 지정된 상태 코드와 응답 바디를 반환합니다.

- **상태 코드**: HTTP 상태 코드 설정 (기본 403)
- **응답 바디**: 커스텀 응답 본문

### 2. Modify Request (요청 수정)

서버로 전달되기 전에 요청을 수정합니다.

- **헤더 추가**: 새로운 요청 헤더 추가
- **헤더 제거**: 기존 요청 헤더 제거
- **바디 변경**: 요청 본문 교체

### 3. Modify Response (응답 수정)

서버 응답을 클라이언트에 전달하기 전에 수정합니다.

- **상태 코드 변경**: HTTP 상태 코드 수정
- **헤더 추가/제거**: 응답 헤더 조작
- **바디 변경**: 응답 본문 교체

### 4. Map Local (로컬 파일 매핑)

요청에 대해 로컬 파일의 내용을 응답으로 반환합니다.

- **파일 경로**: 로컬 파일 시스템의 파일 경로
- **상태 코드**: 커스텀 HTTP 상태 코드
- **응답 헤더**: 커스텀 응답 헤더

### 5. Map Remote (원격 URL 매핑)

요청을 다른 URL로 리다이렉트합니다.

- **타겟 URL**: 요청을 보낼 대상 URL
- **경로 유지**: 원본 요청의 경로를 타겟 URL에 유지할지 여부

---

## 규칙 설정

### 패턴 매칭

와일드카드 패턴을 사용하여 URL을 매칭합니다.

```
*ads.example.com*       # ads.example.com 포함 URL
*api.example.com/v1/*   # 특정 API 경로
*.json                  # JSON 파일 요청
```

### HTTP 메서드 필터

선택적으로 HTTP 메서드를 지정하여 특정 메서드만 매칭할 수 있습니다.

- GET, POST, PUT, DELETE, PATCH 등
- 미지정 시 모든 메서드에 적용

### 규칙 활성화/비활성화

각 규칙은 개별적으로 활성화/비활성화할 수 있습니다.

---

## 사용 방법

### Desktop

1. 사이드바에서 **Intercept Rules** 메뉴 선택
2. **규칙 추가** 버튼 클릭
3. 패턴, 액션 타입, 옵션 설정
4. 저장

트래픽 테이블에서 트랜잭션을 선택하여 빠르게 규칙을 생성할 수도 있습니다.

### TUI

1. **Rules** 탭으로 이동
2. 규칙 추가/편집/삭제 가능
3. 패턴과 액션 타입을 폼으로 입력

### MCP

AI 어시스턴트를 통해 규칙을 관리할 수 있습니다.

```
"example.com 도메인을 차단하는 규칙을 추가해줘"
"API 응답에 CORS 헤더를 추가하는 규칙을 만들어줘"
```
