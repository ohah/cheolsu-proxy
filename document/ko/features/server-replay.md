# Server Replay

캡처된 HTTP 응답을 저장하여, 동일한 요청이 들어올 때 서버에 요청하지 않고 저장된 응답을 반환합니다.

---

## 동작 방식

1. 캡처된 HTTP 트랜잭션의 응답을 Server Replay 엔트리로 저장
2. 이후 동일한 요청(메서드 + URL 매칭)이 들어오면
3. 저장된 응답을 자동으로 반환 (서버 요청 우회)

---

## 용도

- **오프라인 테스트**: 서버 없이 이전 응답으로 테스트
- **응답 시간 단축**: 느린 API 응답을 즉시 반환
- **불안정한 서버 대체**: 간헐적으로 실패하는 서버의 정상 응답 보존
- **API 모킹**: 개발 중 백엔드 의존성 제거

---

## 사용 방법

### Desktop

1. 사이드바에서 **Server Replay** 메뉴 선택
2. 네트워크 대시보드에서 응답이 있는 트랜잭션을 선택하여 추가
3. 활성화/비활성화 토글로 기능 제어
4. 개별 엔트리 삭제 또는 전체 삭제 가능

### 엔트리 정보

각 엔트리는 다음 정보를 표시합니다:

- HTTP 메서드
- URL
- 응답 상태 코드
- 헤더 수
- 바디 크기

> 동일한 URL의 중복 엔트리는 자동으로 방지됩니다.
