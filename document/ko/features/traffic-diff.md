# Traffic Diff

## 개요

Traffic Diff는 두 개의 HTTP 트랜잭션을 비교하여 차이점을 시각적으로 표시하는 기능입니다. 요청과 응답의 헤더, 바디, 상태 코드 등을 항목별로 비교하여 변경된 부분을 정확하게 파악할 수 있습니다.

API 변경 전후의 응답 비교, 환경별(개발/스테이징/프로덕션) 응답 차이 확인, 버그 재현 시 정상/비정상 요청 비교 등에 활용할 수 있습니다.

---

## 비교 항목

### 요청 비교

| 항목            | 설명                          |
| --------------- | ----------------------------- |
| **HTTP 메서드** | GET, POST 등 메서드 변경 감지 |
| **URL**         | 요청 URL 차이                 |
| **헤더**        | 추가, 제거, 변경된 헤더       |
| **바디**        | 요청 본문 차이                |

### 응답 비교

| 항목          | 설명                         |
| ------------- | ---------------------------- |
| **상태 코드** | HTTP 상태 코드 변경          |
| **헤더**      | 추가, 제거, 변경된 응답 헤더 |
| **바디**      | 응답 본문 차이               |

---

## 비교 방식

### 헤더 비교

헤더는 키-값 쌍으로 비교하여 세 가지 변경 타입으로 분류합니다:

- **Added**: 새로 추가된 헤더
- **Removed**: 제거된 헤더
- **Modified**: 동일 키의 값이 변경된 헤더

### JSON 비교

바디가 JSON인 경우, 구조적 비교를 수행합니다. JSON 경로(예: `.data.users[0].name`)와 함께 변경 타입, 이전/이후 값을 표시합니다.

### 텍스트 비교

JSON이 아닌 텍스트 바디는 줄 단위로 비교하여 추가, 삭제, 변경 없음으로 분류합니다.

### 바이너리 비교

바이너리 바디는 크기 차이만 표시합니다.

## 사용 방법

### Desktop

1. 트래픽 목록에서 비교할 첫 번째 트랜잭션 선택
2. 두 번째 트랜잭션을 선택하여 Diff 비교 실행
3. 요청/응답별 차이를 확인

### MCP

```
"트랜잭션 A와 B의 차이를 비교해줘"
```
